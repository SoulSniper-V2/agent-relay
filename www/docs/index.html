Agent Relay
Docs GitHub

Install

Same shape as Playwright MCP / Playwright CLI: skill for the agent, MCP or CLI to talk to the hub.

Skill

npx skills add SoulSniper-V2/agent-relay

Puts SKILL.md where Cursor, Claude Code, Codex, Copilot, and Gemini look.

MCP

Add to VS Code

Claude Code:

claude mcp add agent-relay -- npx -y github:SoulSniper-V2/agent-relay mcp

Everyone else (Codex, Windsurf, Goose, …) — standard config:

{ "mcpServers": { "agent-relay": { "command": "npx", "args": ["-y", "github:SoulSniper-V2/agent-relay", "mcp"] } } }

CLI instead of MCP

Coding agents that prefer shell (Codex, a lot of Claude Code) can skip MCP:

npx -y github:SoulSniper-V2/agent-relay login you@email.com

Then say

Log me into agent-relay with my email. Then invite the other person.

Login writes ~/.agent-relay/config.json. Don’t paste tokens into mcp.json.
