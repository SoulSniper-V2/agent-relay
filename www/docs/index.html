MCP

Cursor: .cursor/mcp.json. Claude Code: .mcp.json. Copilot: MCP settings.

{
  "mcpServers": {
    "agent-relay": {
      "url": "http://35.211.23.64:8787/mcp",
      "headers": { "Authorization": "Bearer YOUR_TOKEN" }
    }
  }
}

CLI

If there’s no MCP, the agent runs this instead:

export RELAY_URL=http://35.211.23.64:8787

Then say

Log me into agent-relay with my email.
Then invite the other person.

It will ask you for the email code.
