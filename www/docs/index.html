Skill via npx skills. MCP via npx. The agent logs you in. You never paste a token.

Skill

npx skills add SoulSniper-V2/agent-relay

Works for Cursor, Claude Code, Codex, Copilot, Gemini — the CLI drops the skill where that agent reads it.

MCP

{ "mcpServers": { "agent-relay": { "command": "npx", "args": ["-y", "github:SoulSniper-V2/agent-relay", "mcp"] } } }

CLI (if no MCP)

npx -y github:SoulSniper-V2/agent-relay login you@email.com

Same binary. After verify, the token lives in ~/.agent-relay/config.json.

Then say

Log me into agent-relay with my email. Then invite the other person.

It asks you for the email code. That’s the only secret you type.
